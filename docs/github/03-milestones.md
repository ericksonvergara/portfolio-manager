# Objetivo

Documentar la configuración oficial de los **Milestones** del proyecto
**Portfolio Manager**. Cada Milestone representa un Sprint del proyecto
y se utiliza para agrupar las Issues que serán desarrolladas durante
cada iteración.

------------------------------------------------------------------------

# Estrategia

-   Cada **Milestone** corresponde a **un Sprint**.
-   Los Milestones se utilizan para planificar y medir el avance del
    proyecto.
-   En esta fase **no se asignan fechas**, ya que primero se construirá
    el backlog completo y posteriormente se realizará la
    calendarización.

# Relación con el Roadmap

Los Milestones fueron definidos con base en el Sprint Development
Roadmap y reflejan la planificación del proyecto.

------------------------------------------------------------------------

# Reglas de uso

1.  Toda Issue deberá pertenecer a un único Milestone.
2.  Un Milestone se cerrará únicamente cuando todas sus Issues estén en
    estado **✅ Done**.
3.  Las fechas de inicio y fin se asignarán durante la planificación
    detallada del proyecto.
4.  El progreso del Milestone será calculado automáticamente por GitHub
    según las Issues cerradas.
